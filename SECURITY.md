# Безопасность

Не публикуйте SECRET_KEY, private Reality/TLS keys, токены панели, подписки или
логи с такими значениями. Приватный репозиторий также не предназначен для
хранения рабочих серверных credentials.

Перед обращением выполните readonly диагностику:

```bash
sudo bash /root/nuvrion-xhttp-install.sh --self-check
ntc check
```

Укажите версию, условия воспроизведения и влияние без credentials. Для
уязвимостей используйте закрытый канал Report a vulnerability, если он доступен;
при его отсутствии не прикладывайте рабочие секреты к Issue.

Для этой версии поддерживается только сохранение установленного образа ноды и
Xray. SSH, реальные UUID, существующие ключи и live generated core config не
изменяются установщиком. Production rollout требует проверки собственных
версий, backup и согласованного окна обслуживания.
