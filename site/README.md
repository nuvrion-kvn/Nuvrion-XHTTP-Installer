# Атлас пива

Статическая русско-английская версия каталога из 96 сортов пива: подробные карточки, состав, крепость, место производства, поиск, фильтры, избранное, прозрачный интерфейс и Animated Topography. Файлы в `dist/` обслуживаются Nginx из корня домена. Сборка фронтенда и Node.js на сервере не требуются.

`tools/build_xhttp.py` в корне репозитория встраивает **все** файлы `dist/` в установщик по пути `beer-atlas/public/` и обновляет `SHA256SUMS`. Все изображения, шрифты, модули, каталог и лицензии локальные. Ссылки на производителей открываются только по действию посетителя.

Для проверок разработчика нужны Node.js 24 и Python с Pillow:

```bash
npm ci --prefix site --ignore-scripts
npm test --prefix site
python3 site/scripts/check-assets.py
```

Тесты проверяют данные, языки, поиск, фильтры, карточки, избранное, управление анимацией, ошибки загрузки и ресурсы. DOM-проверки не заменяют визуальную проверку настоящего Safari/iPhone.

Лицензии перечислены в `LICENSES.md`, происхождение и обработка изображений — в `ASSETS.md`, решения по дизайну — в `DESIGN.md`.
